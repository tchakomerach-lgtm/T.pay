# L12.4 — Operational observability, SLO and alerting

This layer records operational evidence; it does not mutate financial truth.

## Togo/Africa profile
- latency, queue depth, provider availability and offline backlog can be measured as integer values;
- SMS/internal-queue alert routes can be preferred where internet access is degraded;
- alerts carry correlation IDs so field incidents can be reconciled after reconnection;
- SLOs are policy data, not claims that production performance already meets the target.

## Exit gates
1. exact-head CI green;
2. PostgreSQL concurrent alert upsert/race test;
3. alert routing integration with L12.3 routes;
4. provider outage/degraded-mode drill;
5. dashboards for API, Ledger-adjacent queues, provider callbacks, offline backlog and reconciliation;
6. named operational owners and escalation windows.
