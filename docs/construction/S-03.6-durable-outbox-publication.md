# S-03.6 — Durable Outbox / Event Publication

## Threat gate
Assets: committed financial state, domain-event integrity, event delivery identity.
Controls: same-transaction outbox persistence, stable event identity, post-commit publication, retryable unpublished state, worker claim recovery, secret exclusion.

## Incident rule
Material failures are blockers until root cause is resolved. GitHub ReadTimeout requires authoritative state verification before any mutation retry. CI failures require root-cause correction.
