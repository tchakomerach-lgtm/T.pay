# T.Pay AI — L17.1 Security Construction Record

## Scope

L17.1 secures the omnichannel AI skill layer from UI/API input through AI orchestration, capability authorization, provider adapters and audit boundaries.

## Security chain

UI/mobile/web
→ input/schema validation
→ authenticated session
→ organization/tenant binding
→ agent identity
→ skill registry
→ capability broker
→ contextual policy
→ consent/opt-out
→ risk evaluation
→ step-up / human approval
→ idempotency/replay protection
→ secure provider adapter
→ provider webhook verification
→ reconciliation
→ audit/telemetry

The model never constitutes an authorization decision.

## Security invariants

- External channel content is untrusted.
- Provider credentials never enter model context.
- A skill declaration never grants authorization.
- Capability discovery never grants capability.
- Organization context is mandatory.
- High/critical side effects require idempotency and approval according to policy.
- Financial actions remain inside Financial Core.
- Communication adapters cannot write Ledger/Wallet/Credit/KYC directly.
- Provider webhooks require signature/freshness/replay/tenant checks.
- Outbound provider hosts are allowlisted and HTTPS/TLS 1.3 constrained.
- Bulk communication requires consent, suppression, quotas and audit.
- Publication is validated before external execution.
- Human handoff revokes or regenerates call-scoped capabilities.

## AI-specific threat controls

Prompt injection is treated as untrusted input. Tool authorization is enforced outside the model. High-impact actions require independent validation and exact approval binding. Adversarial regression is a CI release gate.

MCP/tool metadata is treated as a supply-chain and tool-poisoning surface. Reviewed tool definitions must be pinned and capability/schema changes require review.

## Web/API security baseline

OWASP ASVS 5.0 is the application verification baseline. API and backend communication controls require explicit methods, authenticated service communication, least privilege and outbound allowlists.
