# S-03.2 — Signed Callback Parser / Verification

## Goal

Convert an untrusted provider HTTP callback into a verified callback envelope without touching financial state.

## Implemented

- strict provider/event/timestamp/signature parsing;
- exact raw-body preservation;
- HMAC-SHA256 verification;
- constant-time comparison;
- configurable freshness;
- runtime secret resolution;
- atomic replay-claim contract;
- body-size bound;
- negative tests for malformed, stale, forged and replayed callbacks.

## Acceptance

- forged signature rejected;
- modified body rejected;
- stale callback rejected;
- duplicate callback rejected;
- replay race prevented by claim contract;
- oversized/malformed envelope rejected;
- exact raw body used;
- no financial mutation;
- CI green.

## Remaining

- durable production replay claim coupled to PostgreSQL settlement boundary;
- provider-specific callback schemas;
- live provider HTTP clients;
- provider-event-to-settlement integration.
