# S-03.2 — CI Gate

The S-03.2 branch must be validated on its latest head SHA before merge.

Required validation:
- TypeScript/build checks pass.
- Security tests pass.
- High-severity production dependency audit passes.
- The GitHub Actions `quality` job is green on the latest PR head.

A previous successful run on an older SHA is not sufficient; GitHub requires required checks to pass for the latest commit.
