# T.Pay Logo Family 02 — Motion

Family 02 is an intentional second visual family for digital/product surfaces. It is not a second brand and must never be redrawn independently.

Canonical source: tpay-family-02-master.svg

Derived assets:
- tpay-family-02-web.svg — web/PWA header
- tpay-family-02-mobile.svg — mobile/app icon
- tpay-family-02-document.svg — reports, bulletins and administrative documents

Every derivative preserves the upward transaction arrow, T.Pay wordmark geometry, green brand signal and dark ink foundation. Only layout, scale and safe-area composition may change.

Prohibited: third geometry inside a module; payment-success animation in the logo; verification/paid/security badges; logo as authorization signal; customer/KYC/payment data in SVG metadata.

Runtime selection must use the centralized brand registry. Modules must not hard-code arbitrary logo paths.
